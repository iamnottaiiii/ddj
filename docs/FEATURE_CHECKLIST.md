# Verified feature checklist

## Verified in the current build

- [x] Local IndexedDB creation, autosave, bounded revision snapshots, local trash, restore, and permanent deletion.
- [x] Home, local-file filtering, favorites, tags, rename, duplicate, details, universal local search, tabs, command palette, settings, and keyboard shortcuts.
- [x] Writer rich-text controls, find/replace, word/character count, local print flow, and HTML/Markdown/text export.
- [x] Sheets editable grid, multiple sheets, formulas/ranges/circular-reference display, sorting, row/column additions, and CSV import/export.
- [x] Slides: create/delete/reorder-by-selection, text and shapes, drag placement, size controls, notes, local presentation mode, and portable HTML export.
- [x] Notes, local calendar event CRUD/repeat metadata, task CRUD/priority/due dates/drag ordering, and Home surfaces.
- [x] Forms builder, required validation, local response collection, CSV export, self-contained form package, and response import.
- [x] Whiteboard sticky/text/shape/line objects, selection, drag, edit, rotation, local save, and SVG export.
- [x] Backup/restore merge-or-replace, storage estimation, PWA manifest/service worker, responsive/density/high-contrast/reduced-motion styles.

## Intentionally not shown as supported

- [ ] Remote collaboration, cloud sync, accounts, sign-in, billing, telemetry, hosted AI, or shared live forms.
- [ ] XLSX/PPTX import/export or native Windows installer. These require additional bundled desktop libraries/packaging that are not represented by a misleading control in the app.
